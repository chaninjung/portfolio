Li-ion Battery Defect Rate Reduction via XGBoost

POSCO Academy · Award

Analyzed real production data from a lithium-ion battery formation process to identify defect-causing factors and build a predictive model to reduce the defect rate.

  • Dataset: 44,078 observations × 113 process variables + 26 time-series variables
  • Feature selection via ANOVA, Chi-squared, Decision Tree — identified charge/discharge equipment and temperature as key factors
  • Defect rate reduced from 3.12% → 0.45% using XGBoost prediction model
  • Domain insight: outlier temperatures (25°–30°C) validated against literature and preserved, not removed

Smart Farm AI — Tomato Ripeness & Disease Detection

POSCO Academy · Award

Built a real-time YOLOv5-based detection system for tomato ripeness (3 classes) and disease (10 classes). Resolved class imbalance by training a GAN from scratch to generate synthetic ripeness images — and published the augmented dataset publicly on Roboflow.

  • Ripeness dataset: 2,448 images (turning/pink/red — class imbalance in "turning")
  • GAN generated 600 synthetic "turning" images → final training set: 3,088 images; FID-optimized parameters
  • Turning class mAP50: 0.969 → 0.991 after GAN augmentation; final ripeness mAP50: 0.973
  • Disease model: compared YOLOv5/v6/v8 → YOLOv5 selected at mAP50 0.991
  • RFID + Arduino for tomato location tracking; Flask web dashboard for real-time detection feed

BM25-based Retrieval-Augmented Compliance Verification for Korean Construction Standards

A domain-specific RAG system for Korean construction regulations. A structure-preserving Markdown–HTML preprocessing pipeline reduces token overhead by 78%, and BM25-based sparse retrieval with Kiwi morphological decomposition enables clause-level terminology alignment and citation-grounded verification. Evaluation on 50 expert-curated compliance questions shows improved accuracy (76.0% → 84.0%) and elimination of false positives (11 → 0). Presentation scheduled at ASCE i3CE 2026, Songdo, June 2026.

IEEE Access — SCI 2023 · First Author

Counter-Rotating Hoop Stabilizer and SVR Control for Two-Wheels Vehicle Applications  ↗ IEEE

The capstone design project won the Grand Prize (2021) and was awarded research funding to continue development. The PID-controlled reaction wheel system was then fully redesigned for this SCI paper: replaced PID with SVR (Support Vector Regression), and replaced the single reaction wheel with a counter-rotating hoop — two wheels spinning in opposite directions to achieve more stable, bidirectional balance control. SVR predicted the required PWM voltage at each tilt angle; hyperparameter optimization with RBF kernel achieved 98.2% correlation.
